# 📊 SQL Employees CRUD Guide (MySQL)

---

## 📌 Overview

This project demonstrates **complete SQL lifecycle operations** including:

* Database creation
* Table creation with constraints
* Alter operations (ADD / MODIFY / DROP)
* CRUD operations (INSERT, UPDATE, DELETE)
* TRUNCATE and DROP usage

---

## 🏗️ Step 1: Create Database

```sql
CREATE DATABASE company_db;
```

```sql

```

## 🧱 Step 3: Create Supporting Table (Departments)

> Required because `employees.dept_id` has a foreign key

```sql
CREATE TABLE depts (
    dept_id INT PRIMARY KEY AUTO_INCREMENT,
    dept_name VARCHAR(50) NOT NULL
);
```

### ➕ Insert Sample Departments

```sql
INSERT INTO depts (dept_name) VALUES
('HR'),
('Finance'),
('IT');
```

### 📋 Departments Table

| dept_id | dept_name |
| ------- | --------- |
| 1       | HR        |
| 2       | Finance   |
| 3       | IT        |

---

## 🧱 Step 4: Create Employees Table

```sql
CREATE TABLE employees(
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50),
    age INT,
    salary INT NOT NULL,
    status VARCHAR(20) DEFAULT 'active',
    dept_id INT,
    joining_date DATE,
    FOREIGN KEY (dept_id) REFERENCES depts(dept_id),
    CHECK (age >= 18)
);
```

---

## 🔄 Step 5: ALTER Operations

### ➕ Add Column

```sql
ALTER TABLE employees
```

### 🔁 Modify Column Type

```sql
ALTER TABLE employees
```

### ❌ Drop Column


## 🔄 Step 7: Update Data



### 📊 After Delete

| id | name    |
| -- | ------- |
| 1  | Alice   |
| 3  | Charlie |

---

## ⚡ Step 9: TRUNCATE Table

```sql
TRUNCATE TABLE employees;
```

### 📌 Behavior

* Removes **all rows**
* Keeps **table structure**
* Resets **AUTO_INCREMENT**

---

## 💣 Step 10: DROP Table

```sql
DROP TABLE employees;
```

### 📌 Behavior

* Deletes **table structure + data permanently**

---

## 💣 Step 11: DROP Database

```sql
DROP DATABASE company_db;
```

### 📌 Behavior

* Deletes **entire database + all tables**

---

## 📚 Key Concepts Summary

| Operation       | Description            |
| --------------- | ---------------------- |
| CREATE DATABASE | Creates new DB         |
| USE             | Selects DB             |
| CREATE TABLE    | Creates structure      |
| ALTER           | Modify table           |
| INSERT          | Add data               |
| UPDATE          | Modify data            |
| DELETE          | Remove specific rows   |
| TRUNCATE        | Remove all rows (fast) |
| DROP TABLE      | Remove table           |
| DROP DATABASE   | Remove entire DB       |

---

## ⚠️ Important Notes

* `CHECK(age >= 18)` ensures valid employee age
* `FOREIGN KEY` ensures department integrity
* `TRUNCATE` is faster than `DELETE`
* `DROP` is irreversible
