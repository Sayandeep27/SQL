# 1. UPDATE

## Definition

`UPDATE` is used to modify existing records in a table.

## Basic Syntax

```sql
UPDATE table_name
SET column1 = value1, column2 = value2
WHERE condition;
```

If `WHERE` is not used, **all rows will be updated**.

---

## Example 1: Update salary of a specific employee

```sql
UPDATE employees
SET salary = 75000
WHERE name = 'Raj';
```

### Table Before Update

| id | name | department | salary | city      |
| -- | ---- | ---------- | ------ | --------- |
| 1  | Amit | IT         | 60000  | Mumbai    |
| 2  | Neha | HR         | 50000  | Delhi     |
| 3  | Raj  | IT         | 70000  | Bangalore |

### Table After Update

| id | name | department | salary | city      |
| -- | ---- | ---------- | ------ | --------- |
| 3  | Raj  | IT         | 75000  | Bangalore |

---

## Example 2: Update multiple columns

```sql
UPDATE employees
SET department = 'Management', salary = 80000
WHERE name = 'Priya';
```

---

## Example 3: Update multiple rows

```sql
UPDATE employees
SET salary = salary + 5000
WHERE department = 'HR';
```

---

# 2. DELETE

## Definition

`DELETE` removes records from a table.

## Basic Syntax

```sql
DELETE FROM table_name
WHERE condition;
```

If `WHERE` is not used, **all rows will be deleted**.

---

## Example 1: Delete a specific employee

```sql
DELETE FROM employees
WHERE name = 'Karan';
```

### Table Before Delete

| id | name  | department | salary | city |
| -- | ----- | ---------- | ------ | ---- |
| 5  | Karan | HR         | 48000  | Pune |

### Table After Delete

| id            | name | department | salary | city |
| ------------- | ---- | ---------- | ------ | ---- |
| (Row removed) |      |            |        |      |

---

## Example 2: Delete multiple rows

```sql
DELETE FROM employees
WHERE department = 'HR';
```

---

## Example 3: Delete all rows

```sql
DELETE FROM employees;
```

# 3. LIMIT

## Definition

`LIMIT` restricts the number of rows returned by a query.

It is commonly used with `SELECT`.

## Basic Syntax

```sql
SELECT *
FROM table_name
LIMIT number_of_rows;
```

---

## Example 1: Get first 3 rows

```sql
SELECT *
FROM employees
LIMIT 3;
```

### Result

| id | name | department | salary | city      |
| -- | ---- | ---------- | ------ | --------- |
| 1  | Amit | IT         | 60000  | Mumbai    |
| 2  | Neha | HR         | 50000  | Delhi     |
| 3  | Raj  | IT         | 70000  | Bangalore |

---

## Example 2: LIMIT with OFFSET

```sql
SELECT *
FROM employees
LIMIT 2 OFFSET 2;
```

### Result

| id | name  | department | salary | city      |
| -- | ----- | ---------- | ------ | --------- |
| 3  | Raj   | IT         | 70000  | Bangalore |
| 4  | Priya | Finance    | 65000  | Mumbai    |

---

## Example 3: LIMIT with ORDER BY

```sql
SELECT *
FROM employees
ORDER BY salary DESC
LIMIT 2;
```

### Result

| id | name  | department | salary | city      |
| -- | ----- | ---------- | ------ | --------- |
| 3  | Raj   | IT         | 70000  | Bangalore |
| 4  | Priya | Finance    | 65000  | Mumbai    |

---

# Summary

| Command | Purpose                          |
| ------- | -------------------------------- |
| UPDATE  | Modify existing records          |
| DELETE  | Remove records from a table      |
| LIMIT   | Restrict number of rows returned |

---

# Best Practices

* Always use **WHERE clause** with UPDATE and DELETE
* Test queries with **SELECT first**
* Use **LIMIT when exploring large datasets**
