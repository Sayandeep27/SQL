# EXISTS

## Definition

EXISTS checks whether a subquery returns any row.

If the subquery returns at least one row → TRUE.

## Syntax

```sql
SELECT column
FROM table1
WHERE EXISTS (
    SELECT column
    FROM table2
    WHERE condition
);
```

## Example

Find customers who have placed orders.

```sql
SELECT name
FROM Customers c
WHERE EXISTS (
    SELECT 1
    FROM Orders o
    WHERE o.customer_id = c.id
);
```

### Output

| name |
| ---- |
| Aman |
| Riya |
| Sara |

Explanation: John has no orders so he is excluded.

# ANY

## Definition

ANY compares a value with any value returned by a subquery.

Condition becomes TRUE if at least one comparison is TRUE.

## Syntax

```sql
SELECT column
FROM table
WHERE column operator ANY (
    SELECT column
    FROM table
);
```

## Example

Find customers whose order amount is greater than ANY order amount of customer 2.

```sql
SELECT name
FROM Customers
WHERE id IN (
    SELECT customer_id
    FROM Orders
    WHERE amount > ANY (
        SELECT amount
        FROM Orders
        WHERE customer_id = 2
    )
);
```

---

# ALL

## Definition

ALL compares a value with ALL values returned by a subquery.

Condition becomes TRUE only if it is TRUE for every value.

## Syntax

```sql
SELECT column
FROM table
WHERE column operator ALL (
    SELECT column
    FROM table
);
```

## Example

Find orders whose amount is greater than ALL orders of customer 2.

```sql
SELECT *
FROM Orders
WHERE amount > ALL (
    SELECT amount
    FROM Orders
    WHERE customer_id = 2
);
```

---

# Difference Between EXISTS, ANY, ALL

| Feature | EXISTS                       | ANY                         | ALL                          |
| ------- | ---------------------------- | --------------------------- | ---------------------------- |
| Purpose | Checks row existence         | Compare with any value      | Compare with all values      |
| Returns | TRUE if subquery returns row | TRUE if one comparison TRUE | TRUE if all comparisons TRUE |
| Usage   | Correlated subqueries        | Comparison queries          | Strict comparisons           |

---

# Summary

EXISTS checks if a subquery returns rows.

ANY checks if condition is true for at least one value.

ALL checks if condition is true for every value.
