# SQL Student Table Practice Queries

This repository contains **basic to intermediate SQL practice queries**
using a sample **Student table**.\
These queries cover string functions, filtering, aggregation, grouping,
sorting, and updates.

# SQL Queries

## 1. Fetch FIRST_NAME in Uppercase with Alias

``` sql
SELECT UPPER(FIRST_NAME) AS STUDENT_NAME
FROM Student;
```

------------------------------------------------------------------------

## 2. Fetch Unique MAJOR Subjects

``` sql
SELECT DISTINCT MAJOR
FROM Student;
```

Alternative:

``` sql
SELECT MAJOR
FROM Student
GROUP BY MAJOR;
```

------------------------------------------------------------------------

## 3. Print First 3 Characters of FIRST_NAME

``` sql
SELECT SUBSTRING(FIRST_NAME,1,3)
FROM Student;
```

------------------------------------------------------------------------

## 4. Find Position of 'a' in 'Shivansh'

``` sql
SELECT INSTR(LOWER(FIRST_NAME),'a')
FROM Student
WHERE FIRST_NAME = 'Shivansh';
```

------------------------------------------------------------------------

## 5. Fetch Unique MAJOR and Their Length

``` sql
SELECT DISTINCT MAJOR, LENGTH(MAJOR)
FROM Student;
```

------------------------------------------------------------------------

## 6. Replace 'a' with 'A' in FIRST_NAME

``` sql
SELECT REPLACE(FIRST_NAME,'a','A')
FROM Student;
```

------------------------------------------------------------------------

## 7. Combine FIRST_NAME and LAST_NAME

``` sql
SELECT CONCAT(FIRST_NAME,' ',LAST_NAME) AS COMPLETE_NAME
FROM Student;
```

------------------------------------------------------------------------

## 8. Order Students by FIRST_NAME and MAJOR

``` sql
SELECT *
FROM Student
ORDER BY FIRST_NAME ASC, MAJOR DESC;
```

------------------------------------------------------------------------

## 9. Fetch Students Named Prem or Shivansh

``` sql
SELECT *
FROM Student
WHERE FIRST_NAME IN ('Prem','Shivansh');
```

------------------------------------------------------------------------

## 10. Exclude Students Named Prem or Shivansh

``` sql
SELECT *
FROM Student
WHERE FIRST_NAME NOT IN ('Prem','Shivansh');
```

------------------------------------------------------------------------

## 11. FIRST_NAME Ending with 'a'

``` sql
SELECT *
FROM Student
WHERE FIRST_NAME LIKE '%a';
```

------------------------------------------------------------------------

## 12. FIRST_NAME Ending with 'a' and Having 6 Characters

``` sql
SELECT *
FROM Student
WHERE FIRST_NAME LIKE '_____a';
```

------------------------------------------------------------------------

## 13. Students with GPA Between 9.00 and 9.99

``` sql
SELECT *
FROM Student
WHERE GPA BETWEEN 9.00 AND 9.99;
```

------------------------------------------------------------------------

## 14. Count Students in Computer Science

``` sql
SELECT MAJOR, COUNT(*) AS TOTAL_COUNT
FROM Student
WHERE MAJOR = 'Computer Science';
```

------------------------------------------------------------------------

## 15. Students Full Name with GPA Between 8.5 and 9.5

``` sql
SELECT CONCAT(FIRST_NAME,' ',LAST_NAME) AS FULL_NAME
FROM Student
WHERE GPA BETWEEN 8.5 AND 9.5;
```

------------------------------------------------------------------------

## 16. Number of Students in Each MAJOR (Descending)

``` sql
SELECT MAJOR, COUNT(MAJOR)
FROM Student
GROUP BY MAJOR
ORDER BY COUNT(MAJOR) DESC;
```

------------------------------------------------------------------------

## 17. Show Only Odd Rows

``` sql
SELECT *
FROM Student
WHERE STUDENT_ID % 2 != 0;
```

------------------------------------------------------------------------

## 18. Top 5 Students by GPA

``` sql
SELECT *
FROM Student
ORDER BY GPA DESC
LIMIT 5;
```

------------------------------------------------------------------------

## 19. Find the 5th Highest GPA

``` sql
SELECT *
FROM Student
ORDER BY GPA DESC
LIMIT 4,1;
```

------------------------------------------------------------------------

## 20. MAJOR Subjects with Less Than 4 Students

``` sql
SELECT MAJOR, COUNT(MAJOR) AS MAJOR_COUNT
FROM Student
GROUP BY MAJOR
HAVING COUNT(MAJOR) < 4;
```

------------------------------------------------------------------------

## 21. Number of Students in Each MAJOR

``` sql
SELECT MAJOR, COUNT(MAJOR) AS ALL_MAJOR
FROM Student
GROUP BY MAJOR;
```

------------------------------------------------------------------------

## 22. Maximum GPA in Each MAJOR

``` sql
SELECT MAJOR, MAX(GPA) AS MAX_GPA
FROM Student
GROUP BY MAJOR;
```

------------------------------------------------------------------------

## 23. Update GPA for Computer Science Students

``` sql
UPDATE Student
SET GPA = 7.5
WHERE MAJOR = 'Computer Science';
```

------------------------------------------------------------------------

## 24. Average GPA for Each MAJOR

``` sql
SELECT MAJOR, AVG(GPA) AS AVERAGE_GPA
FROM Student
GROUP BY MAJOR;
```

------------------------------------------------------------------------

## 25. Top 3 Students with Highest GPA

``` sql
SELECT *
FROM Student
ORDER BY GPA DESC
LIMIT 3;
```

------------------------------------------------------------------------

## 26. Count Students per MAJOR with GPA \> 7.5

``` sql
SELECT MAJOR, COUNT(STUDENT_ID) AS HIGH_GPA_COUNT
FROM Student
WHERE GPA > 7.5
GROUP BY MAJOR;
```
