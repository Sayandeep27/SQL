# 📘 MySQL Functions – Complete Guide

---

## 📌 1. MySQL Numeric Functions

### 🔹 Basic Arithmetic Functions

```sql
SELECT ABS(-10);   -- 10
SELECT CEIL(4.2);  -- 5
SELECT FLOOR(4.9); -- 4
SELECT ROUND(4.567, 2);   -- 4.57
SELECT TRUNCATE(4.567, 2); -- 4.56
```

---

### 🔹 Power & Root

```sql
SELECT POWER(2,3); -- 8
SELECT SQRT(16);   -- 4
```

---

### 🔹 Log Functions

```sql
SELECT LOG(10);
SELECT LOG10(100); -- 2
```

---

### 🔹 Random

```sql
SELECT RAND();
```

---

### 🔹 Sign & Modulus

```sql
SELECT SIGN(-15); -- -1
SELECT MOD(10,3); -- 1
```

---

### 🔹 Min / Max

```sql
SELECT GREATEST(10,20,30);
SELECT LEAST(10,20,30);
```

---

### 🔹 Trigonometric

```sql
SELECT SIN(0);
SELECT COS(0);
SELECT TAN(0);
```

---

### 🔹 Conversion

```sql
SELECT CAST(10.5 AS SIGNED);
```

---

### 📊 Summary Table

| Function   | Purpose         |
| ---------- | --------------- |
| ABS()      | Absolute value  |
| CEIL()     | Round up        |
| FLOOR()    | Round down      |
| ROUND()    | Normal rounding |
| TRUNCATE() | Cut decimals    |
| POWER()    | Exponent        |
| SQRT()     | Square root     |
| RAND()     | Random          |
| MOD()      | Remainder       |
| GREATEST() | Max             |
| LEAST()    | Min             |

## 📌 2. MySQL String Functions

### 🔹 Case Conversion

```sql
SELECT UPPER('hello');
SELECT LOWER('HELLO');
```

---

### 🔹 Length

```sql
SELECT LENGTH('Hello');
SELECT CHAR_LENGTH('Hello');
```

---

### 🔹 Concatenation

```sql
SELECT CONCAT('Hello',' ','World');
SELECT CONCAT_WS('-', '2026','03','30');
```

---

### 🔹 Substring

```sql
SELECT SUBSTRING('Database',1,4);
SELECT LEFT('Database',4);
SELECT RIGHT('Database',4);
```

---

### 🔹 Searching

```sql
SELECT INSTR('Hello World','World');
SELECT LOCATE('World','Hello World');
```

---

### 🔹 Replace & Insert

```sql
SELECT REPLACE('Hello World','World','MySQL');
SELECT INSERT('Hello World',7,5,'MySQL');
```

---

### 🔹 Trim

```sql
SELECT TRIM('   Hello   ');
SELECT LTRIM('   Hello');
SELECT RTRIM('Hello   ');
```

---

### 🔹 Padding

```sql
SELECT LPAD('5',3,'0');
SELECT RPAD('5',3,'0');
```

---

### 🔹 Reverse & Repeat

```sql
SELECT REVERSE('Hello');
SELECT REPEAT('Hi ',3);
```

---

### 🔹 Comparison

```sql
SELECT STRCMP('abc','abc');

```

---

### 🔹 ASCII

```sql
SELECT ASCII('A');
SELECT CHAR(65);
```

## 📌 3. MySQL Date Functions

### 🔹 Current Date & Time

```sql
SELECT CURDATE();
SELECT CURTIME();
SELECT NOW();
```

---

### 🔹 Extract Parts

```sql
SELECT YEAR('2026-03-31');
SELECT MONTH('2026-03-31');
SELECT DAY('2026-03-31');
```

---

### 🔹 Time Parts

```sql
SELECT HOUR(NOW());
SELECT MINUTE(NOW());
SELECT SECOND(NOW());
```

---

### 🔹 Formatting

```sql
SELECT DATE_FORMAT(NOW(), '%d-%m-%Y');
```

---

### 🔹 Date Arithmetic

```sql
SELECT DATE_ADD('2026-03-31', INTERVAL 5 DAY);
SELECT DATE_SUB('2026-03-31', INTERVAL 10 DAY);
```

---

### 🔹 Difference

```sql
SELECT DATEDIFF('2026-04-10','2026-03-31');
SELECT TIMESTAMPDIFF(YEAR,'2000-01-01',CURDATE());
```

---

### 🔹 Day & Week

```sql
SELECT DAYNAME('2026-03-31');
SELECT DAYOFWEEK('2026-03-31');
SELECT WEEK('2026-03-31');
```

---

### 🔹 Last Day

```sql
SELECT LAST_DAY('2026-03-15');
```

---

### 🔹 Conversion

```sql
SELECT STR_TO_DATE('31-03-2026','%d-%m-%Y');
SELECT DATE(NOW());
```

---

### 📊 Summary Table

| Function      | Purpose          |
| ------------- | ---------------- |
| NOW()         | Current datetime |
| CURDATE()     | Current date     |
| YEAR()        | Extract year     |
| MONTH()       | Extract month    |
| DAY()         | Extract day      |
| DATE_ADD()    | Add date         |
| DATE_SUB()    | Subtract date    |
| DATEDIFF()    | Difference       |
| DATE_FORMAT() | Format           |
| LAST_DAY()    | End of month     |

## 📌 4. Real Interview Examples

### 🔹 Numeric Example

```sql
SELECT
    salary,
    ROUND(salary, -3),
    CEIL(salary/1000),
    FLOOR(salary/1000)
FROM employees;
```

---

### 🔹 String Example

```sql
SELECT
    name,
    UPPER(name),
    LENGTH(name),
    CONCAT(name,'@gmail.com')
FROM users;
```

---

### 🔹 Date Example

```sql
SELECT *
FROM employees
WHERE hire_date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY);
```

---

```sql
SELECT
    name,
    TIMESTAMPDIFF(YEAR, dob, CURDATE()) AS age
FROM users;
```
