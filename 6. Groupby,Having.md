# MySQL GROUP BY and HAVING

---

## 1. Introduction

`GROUP BY` and `HAVING` are used in MySQL to work with grouped data. They are commonly used together with **aggregate functions** like `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.

* **GROUP BY**: Groups rows that have the same values in specified columns.
* **HAVING**: Filters grouped results after aggregation.

# PART 1: GROUP BY

---

## 3. What is GROUP BY?

`GROUP BY` groups rows that have the same value in a column.

It is often used with aggregate functions.

### Syntax

```sql
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;
```

---

## 4. Example 1 — Count employees in each department

```sql
SELECT department, COUNT(*) AS total_employees
FROM employees
GROUP BY department;
```

### Result

| department | total_employees |
| ---------- | --------------- |
| IT         | 3               |
| HR         | 3               |
| Finance    | 2               |

Explanation:

MySQL groups rows by department and counts employees in each group.

---

## 5. Example 2 — Average salary by department

```sql
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;
```

### Result

| department | avg_salary |
| ---------- | ---------- |
| IT         | 64000      |
| HR         | 51000      |
| Finance    | 68500      |

Explanation:

The query groups employees by department and calculates average salary.

## 6. Example 3 — Total salary paid per city

# PART 2: HAVING

---

## 8. What is HAVING?

`HAVING` is used to filter **grouped results**.

Difference between `WHERE` and `HAVING`:

| Clause | Works On                         |
| ------ | -------------------------------- |
| WHERE  | Filters rows BEFORE grouping     |
| HAVING | Filters groups AFTER aggregation |

---

## 9. HAVING Syntax

```sql
SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;
```

---

## 10. Example 1 — Departments with more than 2 employees

```sql
SELECT department, COUNT(*) AS total_employees
FROM employees
GROUP BY department
HAVING COUNT(*) > 2;
```

### Result

| department | total_employees |
| ---------- | --------------- |
| IT         | 3               |
| HR         | 3               |

Explanation:

Only departments with more than 2 employees are shown.

---

## 11. Example 2 — Departments where average salary > 60000

```sql
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department
HAVING AVG(salary) > 60000;
```

### Result

| department | avg_salary |
| ---------- | ---------- |
| IT         | 64000      |
| Finance    | 68500      |

---

## 12. Example 3 — Cities where total salary > 100000

```sql
SELECT city, SUM(salary) AS total_salary
FROM employees
GROUP BY city
HAVING SUM(salary) > 100000;
```

### Result

| city   | total_salary |
| ------ | ------------ |
| Mumbai | 130000       |
| Delhi  | 153000       |
| Pune   | 137000       |

# PART 3: WHERE vs HAVING Example

---

## Using WHERE

Filters rows before grouping.

```sql
SELECT department, COUNT(*)
FROM employees
WHERE salary > 60000
GROUP BY department;
```

---

## Using HAVING

Filters groups after aggregation.

```sql
SELECT department, AVG(salary)
FROM employees
GROUP BY department
HAVING AVG(salary) > 60000;
```

---

# PART 4: GROUP BY with Multiple Columns

---

You can group by more than one column.

```sql
SELECT department, city, COUNT(*)
FROM employees
GROUP BY department, city;
```

### Result Example

| department | city      | count |
| ---------- | --------- | ----- |
| IT         | Mumbai    | 2     |
| IT         | Bangalore | 1     |
| HR         | Delhi     | 3     |
| Finance    | Pune      | 2     |

---

# PART 5: GROUP BY with ORDER BY

---

```sql
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department
ORDER BY avg_salary DESC;
```

---

# Key Points

* `GROUP BY` groups rows with same values.
* Works with aggregate functions.
* `HAVING` filters aggregated groups.
* `WHERE` filters rows before grouping.
* `HAVING` is used after `GROUP BY`.

---

# Summary

| Clause   | Purpose                      |
| -------- | ---------------------------- |
| GROUP BY | Groups rows with same values |
| HAVING   | Filters grouped results      |
| WHERE    | Filters rows before grouping |
