# MySQL JOINS (INNER, LEFT, RIGHT, CROSS, SELF)

A complete beginner‑friendly guide to understanding **MySQL Joins** with clear tables, examples, and queries.

---

# 1. What is a JOIN?

A **JOIN** is used to combine rows from two or more tables based on a related column between them.

Most databases are **normalized**, meaning related data is stored in different tables. Joins allow us to retrieve related information together.

Example relationship:

```
employees.dept_id = departments.dept_id
employees.manager_id = managers.manager_id
```

# 3. INNER JOIN

## Definition

`INNER JOIN` returns **only rows that have matching values in both tables**.

Rows without matches are removed.

---

## Syntax

```sql
SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;
```

---

## Example Query

```sql
SELECT employees.emp_name, departments.dept_name
FROM employees
INNER JOIN departments
ON employees.dept_id = departments.dept_id;
```

---

## Result

| emp_name | dept_name |
| -------- | --------- |
| Alice    | HR        |
| Bob      | IT        |
| Charlie  | HR        |
| David    | Finance   |

Employee **Eva** does not appear because `dept_id` is NULL.

---

# 4. LEFT JOIN

## Definition

`LEFT JOIN` returns:

• All rows from the **left table**
• Matching rows from the right table
• If no match exists → NULL values appear

---

## Syntax

```sql
SELECT columns
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;
```

---

## Example Query

```sql
SELECT employees.emp_name, departments.dept_name
FROM employees
LEFT JOIN departments
ON employees.dept_id = departments.dept_id;
```

---

## Result

| emp_name | dept_name |
| -------- | --------- |
| Alice    | HR        |
| Bob      | IT        |
| Charlie  | HR        |
| David    | Finance   |
| Eva      | NULL      |

Eva appears because LEFT JOIN keeps **all employees**.

---

# 5. RIGHT JOIN

## Definition

`RIGHT JOIN` returns:

• All rows from the **right table**
• Matching rows from the left table
• Non‑matching rows show NULL

---

## Syntax

```sql
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;
```

---

## Example Query

```sql
SELECT employees.emp_name, departments.dept_name
FROM employees
RIGHT JOIN departments
ON employees.dept_id = departments.dept_id;
```

---

## Result

| emp_name | dept_name |
| -------- | --------- |
| Alice    | HR        |
| Charlie  | HR        |
| Bob      | IT        |
| David    | Finance   |
| NULL     | Marketing |

Marketing appears because no employee belongs to that department.

# 6. CROSS JOIN

## Definition

`CROSS JOIN` produces **every possible combination of rows** between two tables.

Formula:

```
Total Rows = rows_table1 × rows_table2
```

---

If:

```
Employees = 5 rows
Departments = 4 rows
```

Then result:

```
5 × 4 = 20 rows
```

---

## Syntax

```sql
SELECT columns
FROM table1
CROSS JOIN table2;
```

---

## Example Query

```sql
SELECT employees.emp_name, departments.dept_name
FROM employees
CROSS JOIN departments;
```

---

## Example Output

| emp_name | dept_name |
| -------- | --------- |
| Alice    | HR        |
| Alice    | IT        |
| Alice    | Finance   |
| Alice    | Marketing |
| Bob      | HR        |
| Bob      | IT        |

This continues for all combinations.

# 7. SELF JOIN

## Definition

A **SELF JOIN** joins a table with itself.

Used when rows in the same table are related.

Example: employees and their managers.

---

## Example Table

| emp_id | emp_name | manager_id |
| ------ | -------- | ---------- |
| 1      | Alice    | 3          |
| 2      | Bob      | 3          |
| 3      | Clark    | NULL       |

Clark is the manager.

---

## Query

```sql
SELECT
 e.emp_name AS Employee,
 m.emp_name AS Manager
FROM employees e
LEFT JOIN employees m
ON e.manager_id = m.emp_id;
```

---

## Result

| Employee | Manager |
| -------- | ------- |
| Alice    | Clark   |
| Bob      | Clark   |
| Clark    | NULL    |

Explanation:

```
e = employee table alias
m = manager table alias
```

The same table is used twice.

# 8. Quick Comparison

| Join Type  | Description                         |
| ---------- | ----------------------------------- |
| INNER JOIN | Returns matching rows only          |
| LEFT JOIN  | All rows from left table + matches  |
| RIGHT JOIN | All rows from right table + matches |
| CROSS JOIN | All possible combinations           |
| SELF JOIN  | Table joined with itself            |

---

# 9. Visual Summary

```
INNER JOIN
A ∩ B

LEFT JOIN
All A + matching B

RIGHT JOIN
All B + matching A

CROSS JOIN
A × B

SELF JOIN
A joined with A
```

# 10. Common Interview Query

Get employee name, department, and manager.

```sql
SELECT
 e.emp_name,
 d.dept_name,
 m.manager_name
FROM employees e
LEFT JOIN departments d
ON e.dept_id = d.dept_id
LEFT JOIN managers m
ON e.manager_id = m.manager_id;
```

---

## Result

| emp_name | dept_name | manager_name |
| -------- | --------- | ------------ |
| Alice    | HR        | John         |
| Bob      | IT        | Smith        |
| Charlie  | HR        | John         |
| David    | Finance   | NULL         |
| Eva      | NULL      | Clark        |

---

# 11. Key Takeaways

• JOINs combine data from multiple tables

• INNER JOIN shows only matching rows

• LEFT JOIN keeps all rows from the left table

• RIGHT JOIN keeps all rows from the right table

• CROSS JOIN produces every possible combination

• SELF JOIN joins a table with itself
