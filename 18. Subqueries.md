# 🔥 1. Find 5th Highest CGPA

## ✅ Query

```sql
SELECT *
FROM students s1
WHERE 5 = (
    SELECT COUNT(DISTINCT s2.cgpa)
    FROM students s2
    WHERE s1.cgpa <= s2.cgpa
);
```

## 💡 Explanation

* For each row, count how many **distinct CGPA values are greater than or equal** to it
* When count = 5 → that CGPA is the **5th highest**

# 🔥 2. Find 2nd Highest CGPA

## ✅ Query

```sql
SELECT MAX(cgpa)
FROM students
WHERE cgpa NOT IN (
    SELECT MAX(cgpa) FROM students
);
```

## 💡 Explanation

* First, find highest CGPA
* Then exclude it
* Then take max again → gives **2nd highest**

---

# 🔥 3. Fetch Last Record

## ✅ Query

```sql
SELECT *
FROM students
WHERE student_id = (
    SELECT MAX(student_id)
    FROM students
);
```

## 💡 Explanation

* Assumes **student_id is increasing (auto increment)**
* Last record = highest ID

---

# 🔥 4. Fetch Last 5 Records

## ✅ Query

```sql
SELECT *
FROM (
    SELECT *
    FROM students
    ORDER BY student_id DESC
    LIMIT 5
) AS subquery
ORDER BY student_id;
```

## 💡 Explanation

* First: get latest 5 rows (descending order)
* Then: reorder them ascending for readability

# 🔥 5. Top 3 Maximum CGPA Values

## ✅ Query

```sql
SELECT DISTINCT cgpa
FROM students s1
WHERE 3 >= (
    SELECT COUNT(DISTINCT s2.cgpa)
    FROM students s2
    WHERE s1.cgpa <= s2.cgpa
)
ORDER BY s1.cgpa DESC;
```

## 💡 Explanation

* Same logic as **Nth highest**
* Difference:

  * Here we use `3 >=` → gives **top 3 values**
  * We sort results using `ORDER BY DESC`

# 🚀 Alternative (Window Function - Best Practice)

## Top N Using DENSE_RANK

```sql
SELECT cgpa
FROM (
    SELECT cgpa, DENSE_RANK() OVER (ORDER BY cgpa DESC) AS rnk
    FROM students
) t
WHERE rnk <= 3;
```

## Nth Highest

```sql
SELECT cgpa
FROM (
    SELECT cgpa, DENSE_RANK() OVER (ORDER BY cgpa DESC) AS rnk
    FROM students
) t
WHERE rnk = 5;
```

## 💡 Why Better?

* More readable
* More efficient
* Industry preferred approach
