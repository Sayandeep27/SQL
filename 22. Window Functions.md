# 📊 SQL Window Functions — Complete Interview Guide

---

## 🔹 What are Window Functions?

Window functions perform calculations across a set of rows (window) **without collapsing them like GROUP BY**.

👉 **Key idea:**

* **GROUP BY** → reduces rows
* **WINDOW FUNCTION** → keeps rows + adds extra insight

---

## 🔹 Common Syntax

```sql
FUNCTION_NAME() OVER (
    PARTITION BY column
    ORDER BY column
)
```

* **PARTITION BY** → like grouping
* **ORDER BY** → defines row sequence

# 🔥 1. ROW_NUMBER()

👉 Gives unique sequential number to each row

```sql
SELECT name, dept, salary,
ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC) AS rn
FROM employees;
```

### Output

| name | dept | salary | rn |
| ---- | ---- | ------ | -- |
| B    | IT   | 60000  | 1  |
| C    | IT   | 60000  | 2  |
| A    | IT   | 50000  | 3  |
| E    | HR   | 50000  | 1  |
| D    | HR   | 40000  | 2  |

✅ Even if salary is same → different numbers

---

# 🔥 2. RANK()

👉 Same values → same rank
👉 BUT skips numbers

```sql
SELECT name, dept, salary,
RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS rnk
FROM employees;
```

### Output

| name | dept | salary | rnk |
| ---- | ---- | ------ | --- |
| B    | IT   | 60000  | 1   |
| C    | IT   | 60000  | 1   |
| A    | IT   | 50000  | 3   |

⚠️ Rank 2 is skipped

---

# 🔥 3. DENSE_RANK()

👉 Same values → same rank
👉 NO skipping

```sql
SELECT name, dept, salary,
DENSE_RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS drnk
FROM employees;
```

### Output

| name | dept | salary | drnk |
| ---- | ---- | ------ | ---- |
| B    | IT   | 60000  | 1    |
| C    | IT   | 60000  | 1    |
| A    | IT   | 50000  | 2    |

---

## 🔥 Difference (Very Important)

| Function     | Duplicate Values | Skips Rank? |
| ------------ | ---------------- | ----------- |
| ROW_NUMBER() | ❌ No             | ❌ No        |
| RANK()       | ✅ Yes            | ✅ Yes       |
| DENSE_RANK() | ✅ Yes            | ❌ No        |

---

# 🔥 4. LEAD()

👉 Get next row value

```sql
SELECT name, salary,
LEAD(salary) OVER (ORDER BY salary) AS next_salary
FROM employees;
```

---

# 🔥 5. LAG()

👉 Get previous row value

```sql
SELECT name, salary,
LAG(salary) OVER (ORDER BY salary) AS prev_salary
FROM employees;
```

---

# 🔥 Real Use Cases (Important for Interviews)

## 1. Find Top 2 salaries per department

```sql
SELECT *
FROM (
    SELECT *,
    DENSE_RANK() OVER (PARTITION BY dept ORDER BY salary DESC) AS rnk
    FROM employees
) t
WHERE rnk <= 2;
```

---

## 2. Compare current vs previous employee salary

```sql
SELECT name, salary,
salary - LAG(salary) OVER (ORDER BY emp_id) AS diff
FROM employees;
```

---

## 3. Detect increasing trend

```sql
SELECT *,
CASE
    WHEN salary > LAG(salary) OVER (ORDER BY emp_id)
    THEN 'Increase'
    ELSE 'No Increase'
END
FROM employees;
```

# 🔥 Easy Memory Trick

* **ROW_NUMBER → unique numbering**
* **RANK → competition ranking (1,1,3)**
* **DENSE_RANK → no gaps (1,1,2)**
* **LEAD → next**
* **LAG → previous**

# 🔹 NTH_VALUE()

👉 Returns value from N-th row in a window

```sql
NTH_VALUE(column, N) OVER (
    PARTITION BY column
    ORDER BY column
    ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
)
```

⚠️ **Important:** Frame clause is mandatory for correct result

---

## Example: 2nd Highest Salary

```sql
SELECT name, dept, salary,
NTH_VALUE(salary, 2) OVER (
    PARTITION BY dept
    ORDER BY salary DESC
    ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
) AS second_highest
FROM employees;
```

---

# 🔥 Frame Clause

👉 Defines which rows inside the window are considered

```sql
ROWS BETWEEN start AND end
```

---

## 🔹 Keywords

| Keyword             | Meaning        |
| ------------------- | -------------- |
| UNBOUNDED PRECEDING | From first row |
| CURRENT ROW         | Current row    |
| N PRECEDING         | N rows before  |
| N FOLLOWING         | N rows after   |
| UNBOUNDED FOLLOWING | Till last row  |

---

## 🔥 Important Frames

### 1. Default Frame

```sql
ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
```

👉 Running totals

---

### 2. Full Window Frame

```sql
ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
```

👉 Used in NTH_VALUE(), LAST_VALUE()

---

### 3. Sliding Window

```sql
ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING
```

👉 Moving averages

---

# 🔥 Example: Running Total

```sql
SELECT name, salary,
SUM(salary) OVER (
    ORDER BY salary
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
) AS running_total
FROM employees;
```
