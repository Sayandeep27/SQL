# MySQL CREATE INDEX

---

## 1. What is an Index?

An **Index** in MySQL is a data structure used to improve the speed of data retrieval operations on a table.

Without an index, MySQL must scan the entire table to find rows (Full Table Scan).

With an index, MySQL can quickly locate the rows.

**Example idea:**

Book without index → read every page

Book with index → directly jump to page

---

## 2. Why Index is Used

| Purpose             | Explanation                 |
| ------------------- | --------------------------- |
| Faster Queries      | Speeds up SELECT statements |
| Efficient Searching | Quickly finds rows          |
| Faster Sorting      | Helps ORDER BY              |
| Faster Joins        | Improves JOIN performance   |

---

## 3. Sample Table

```sql
CREATE TABLE employees (
    emp_id INT PRIMARY KEY,
    name VARCHAR(50),
    department VARCHAR(50),
    salary INT,
    city VARCHAR(50)
);
```

### Table Structure

| emp_id | name  | department | salary | city      |
| ------ | ----- | ---------- | ------ | --------- |
| 101    | Rahul | IT         | 60000  | Mumbai    |
| 102    | Priya | HR         | 45000  | Delhi     |
| 103    | Amit  | IT         | 70000  | Bangalore |
| 104    | Neha  | Sales      | 50000  | Pune      |
| 105    | Karan | HR         | 48000  | Mumbai    |

---

## 4. Syntax of CREATE INDEX

```sql
CREATE INDEX index_name
ON table_name(column_name);
```

Example

```sql
CREATE INDEX idx_name
ON employees(name);
```

---

## 5. Single Column Index

Creates index on one column.

```sql
CREATE INDEX idx_department
ON employees(department);
```

Query Example

```sql
SELECT *
FROM employees
WHERE department = 'IT';
```

Index helps MySQL find rows faster.

---

## 6. Composite Index (Multiple Columns)

Index on multiple columns.

```sql
CREATE INDEX idx_dept_salary
ON employees(department, salary);
```

Query Example

```sql
SELECT *
FROM employees
WHERE department = 'IT'
AND salary > 60000;
```

---

## 7. Unique Index

Ensures values are unique.

```sql
CREATE UNIQUE INDEX idx_unique_name
ON employees(name);
```

Duplicate values will not be allowed.

---

## 8. Index Using ALTER TABLE

You can also create index using ALTER TABLE.

```sql
ALTER TABLE employees
ADD INDEX idx_city(city);
```

---

## 9. Show Indexes

To see indexes in a table.

```sql
SHOW INDEX FROM employees;
```

---

## 10. Drop Index

To remove an index.

```sql
DROP INDEX idx_department
ON employees;
```

---

## 11. When to Use Index

| Situation                   | Use Index? |
| --------------------------- | ---------- |
| Frequently searched columns | Yes        |
| Columns used in WHERE       | Yes        |
| Columns used in JOIN        | Yes        |
| Small tables                | Usually No |
| Frequently updated columns  | Avoid      |

---

## 12. Advantages of Index

* Faster SELECT queries
* Faster sorting
* Faster filtering
* Better JOIN performance

---

## 13. Disadvantages of Index

* Extra storage required
* Slower INSERT
* Slower UPDATE
* Slower DELETE

Because indexes must also be updated.

---

## 14. Best Practices

* Do not create too many indexes
* Index columns used in WHERE
* Use composite indexes wisely
* Avoid indexing very small tables

---
