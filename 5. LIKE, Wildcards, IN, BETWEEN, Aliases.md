# 2. LIKE Operator

## What is LIKE?

The **LIKE** operator is used to search for a specified pattern in a column.

It is mostly used with **Wildcards**.

### Syntax

```sql
SELECT column_name
FROM table_name
WHERE column_name LIKE pattern;
```

---

## Example 1: Names starting with 'A'

```sql
SELECT *
FROM employees
WHERE name LIKE 'A%';
```

Result

| emp_id | name  | department | salary | city      |
| ------ | ----- | ---------- | ------ | --------- |
| 3      | Amit  | IT         | 75000  | Bangalore |
| 5      | Arjun | IT         | 90000  | Pune      |

---

## Example 2: Names ending with 'a'

```sql
SELECT *
FROM employees
WHERE name LIKE '%a';
```

Result

| emp_id | name  | department | salary | city  |
| ------ | ----- | ---------- | ------ | ----- |
| 2      | Priya | HR         | 45000  | Delhi |

# 3. Wildcards

Wildcards are special characters used with **LIKE** to search patterns.

## Types of Wildcards

| Wildcard | Meaning                            |
| -------- | ---------------------------------- |
| %        | Represents zero or more characters |
| _        | Represents exactly one character   |

---

## % Wildcard Example

Find names starting with 'S'

```sql
SELECT *
FROM employees
WHERE name LIKE 'S%';
```

Result

| emp_id | name  | department | salary | city   |
| ------ | ----- | ---------- | ------ | ------ |
| 4      | Sneha | Finance    | 50000  | Mumbai |

---

## _ Wildcard Example

Find names with exactly 5 characters

```sql
SELECT *
FROM employees
WHERE name LIKE '_____';
```

Result

| emp_id | name  | department | salary | city      |
| ------ | ----- | ---------- | ------ | --------- |
| 3      | Amit  | IT         | 75000  | Bangalore |
| 5      | Arjun | IT         | 90000  | Pune      |

# 4. IN Operator

## What is IN?

The **IN** operator allows you to specify multiple values in a WHERE clause.

It is used as a shortcut for multiple OR conditions.

### Syntax

```sql
SELECT column_name
FROM table_name
WHERE column_name IN (value1, value2, value3);
```

---

## Example

Find employees who belong to IT or HR departments

```sql
SELECT *
FROM employees
WHERE department IN ('IT','HR');
```

Result

| emp_id | name  | department | salary | city      |
| ------ | ----- | ---------- | ------ | --------- |
| 1      | Rahul | IT         | 60000  | Mumbai    |
| 2      | Priya | HR         | 45000  | Delhi     |
| 3      | Amit  | IT         | 75000  | Bangalore |
| 5      | Arjun | IT         | 90000  | Pune      |
| 6      | Neha  | HR         | 40000  | Delhi     |

# 5. BETWEEN Operator

## What is BETWEEN?

The **BETWEEN** operator is used to filter values within a given range.

The values can be **numbers, text, or dates**.

### Syntax

```sql
SELECT column_name
FROM table_name
WHERE column_name BETWEEN value1 AND value2;
```

---

## Example

Find employees whose salary is between 45000 and 80000

```sql
SELECT *
FROM employees
WHERE salary BETWEEN 45000 AND 80000;
```

Result

| emp_id | name  | department | salary | city      |
| ------ | ----- | ---------- | ------ | --------- |
| 1      | Rahul | IT         | 60000  | Mumbai    |
| 2      | Priya | HR         | 45000  | Delhi     |
| 3      | Amit  | IT         | 75000  | Bangalore |
| 4      | Sneha | Finance    | 50000  | Mumbai    |

# 6. Aliases

## What are Aliases?

Aliases are used to give a **temporary name to a column or table**.

This makes the output easier to read.

Aliases are created using the **AS** keyword.

### Syntax

```sql
SELECT column_name AS alias_name
FROM table_name;
```

---

## Column Alias Example

```sql
SELECT name AS employee_name,
salary AS employee_salary
FROM employees;
```

Result

| employee_name | employee_salary |
| ------------- | --------------- |
| Rahul         | 60000           |
| Priya         | 45000           |
| Amit          | 75000           |
| Sneha         | 50000           |
| Arjun         | 90000           |
| Neha          | 40000           |

---

## Table Alias Example

```sql
SELECT e.name, e.salary
FROM employees AS e;
```

---

# 7. Combining Multiple Concepts

Example: Find employees from IT department whose salary is between 60000 and 95000

```sql
SELECT name, salary
FROM employees
WHERE department = 'IT'
AND salary BETWEEN 60000 AND 95000;
```

Result

| name  | salary |
| ----- | ------ |
| Rahul | 60000  |
| Amit  | 75000  |
| Arjun | 90000  |

# 8. Key Takeaways

| Concept   | Purpose                               |
| --------- | ------------------------------------- |
| LIKE      | Pattern searching                     |
| Wildcards | Used with LIKE for flexible matching  |
| IN        | Multiple value filtering              |
| BETWEEN   | Range filtering                       |
| Aliases   | Temporary names for columns or tables |
