# MySQL: SELECT, DISTINCT, WHERE, AND, OR, NOT

---

## Sample Table: Employees

| id | name  | department | salary | city      |
| -- | ----- | ---------- | ------ | --------- |
| 1  | Amit  | IT         | 60000  | Mumbai    |
| 2  | Sara  | HR         | 45000  | Delhi     |
| 3  | Rahul | IT         | 70000  | Mumbai    |
| 4  | John  | Finance    | 50000  | Bangalore |
| 5  | Neha  | HR         | 45000  | Delhi     |

---

## SELECT

Used to retrieve data from a table.

```sql
SELECT * FROM employees;
```

---

## SELECT DISTINCT

Used to return only unique values. Duplicates are removed.

```sql
SELECT DISTINCT department FROM employees;
```

---

## WHERE

Filters rows based on a condition.

```sql
SELECT * FROM employees
WHERE city = 'Mumbai';
```

---

## AND

Returns records where all conditions are true.

```sql
SELECT * FROM employees
WHERE department = 'IT' AND city = 'Mumbai';
```

---

## OR

Returns records where at least one condition is true.

```sql
SELECT * FROM employees
WHERE department = 'HR' OR city = 'Bangalore';
```

---

## NOT

Negates a condition.

```sql
SELECT * FROM employees
WHERE NOT department = 'HR';
```

---

## Combined Example

```sql
SELECT name, salary
FROM employees
WHERE department = 'IT' AND NOT city = 'Delhi';
```

---

## Summary

| Clause   | Purpose                     |
| -------- | --------------------------- |
| SELECT   | Retrieve columns            |
| DISTINCT | Remove duplicate values     |
| WHERE    | Filter rows                 |
| AND      | All conditions must be true |
| OR       | Any condition can be true   |
| NOT      | Reverse condition           |
