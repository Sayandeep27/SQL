# CASE in MySQL

## What is CASE?

The **CASE statement** works like **IF‑ELSE logic** in SQL.

It allows us to apply conditions and return different values depending on the condition.

---

## Syntax

```sql
SELECT column,
CASE
 WHEN condition1 THEN result1
 WHEN condition2 THEN result2
 ELSE result
END
FROM table_name;
```

---

## Example 1: Categorizing Salary

```sql
SELECT name, salary,
CASE
 WHEN salary >= 80000 THEN 'High Salary'
 WHEN salary >= 50000 THEN 'Medium Salary'
 ELSE 'Low Salary'
END AS salary_category
FROM employees;
```

### Output

| name  | salary | salary_category |
| ----- | ------ | --------------- |
| Rahul | 70000  | Medium Salary   |
| Priya | 50000  | Medium Salary   |
| Amit  | 90000  | High Salary     |
| Neha  | 60000  | Medium Salary   |
| Arjun | 40000  | Low Salary      |

---

## Example 2: Experience Level

```sql
SELECT name, experience,
CASE
 WHEN experience >= 7 THEN 'Senior'
 WHEN experience >= 3 THEN 'Mid-Level'
 ELSE 'Junior'
END AS experience_level
FROM employees;
```

---

## Example 3: Using CASE in ORDER BY

```sql
SELECT name, department
FROM employees
ORDER BY
CASE
 WHEN department='IT' THEN 1
 WHEN department='HR' THEN 2
 ELSE 3
END;
```

This sorts departments in custom order.

---

## Example 4: CASE inside Aggregate Functions

```sql
SELECT
SUM(CASE WHEN department='IT' THEN salary ELSE 0 END) AS total_it_salary
FROM employees;
```

# Comments in MySQL

## What are Comments?

**Comments** are notes written inside SQL queries to explain the code.

They are ignored by MySQL during execution.

They help developers understand queries easily.

---

## Types of Comments in MySQL

| Type         | Syntax        |
| ------------ | ------------- |
| Single Line  | -- comment    |
| Hash Comment | # comment     |
| Multi Line   | /* comment */ |

---

## Single Line Comment

```sql
-- This query selects all employees
SELECT * FROM employees;
```

---

## Hash Comment

```sql
# This query selects IT employees
SELECT * FROM employees
WHERE department='IT';
```

---

## Multi Line Comment

```sql
/*
This query shows employees
with salary greater than 60000
*/

SELECT name, salary
FROM employees
WHERE salary > 60000;
```

---

## Example with Comments in Query

```sql
SELECT name, salary
FROM employees
-- filtering high salary employees
WHERE salary > 60000;
```

---

# Best Practices

• Use comments to explain complex queries

• Avoid too many unnecessary comments

• Write meaningful comments

• Keep comments updated when queries change

---

# Conclusion

The **CASE statement** allows conditional logic directly inside SQL queries, making data transformation easier.

**Comments** help document SQL code so that it is easier for developers and teams to understand and maintain queries.
