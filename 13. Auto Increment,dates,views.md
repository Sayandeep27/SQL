# MySQL: AUTO_INCREMENT, Dates, and Views

---

## 1. AUTO_INCREMENT

### What is AUTO_INCREMENT

AUTO_INCREMENT is used to automatically generate a unique number whenever a new row is inserted.

### Example Table

| id | name | age |
| -- | ---- | --- |
| 1  | A    | 20  |
| 2  | B    | 21  |

### Create Table

```sql
CREATE TABLE students (
 id INT AUTO_INCREMENT PRIMARY KEY,
 name VARCHAR(50),
 age INT
);
```

### Insert Data

```sql
INSERT INTO students (name, age) VALUES ('A',20);
INSERT INTO students (name, age) VALUES ('B',21);
```

## 2. Dates in MySQL

### Date Data Types

| Type      | Description                 |
| --------- | --------------------------- |
| DATE      | Stores date                 |
| DATETIME  | Date and time               |
| TIMESTAMP | Date and time with timezone |
| TIME      | Stores time                 |
| YEAR      | Stores year                 |

### Example Table

| id | name | joining_date |
| -- | ---- | ------------ |
| 1  | A    | 2024-01-01   |

### Create Table

```sql
CREATE TABLE employees (
 id INT AUTO_INCREMENT PRIMARY KEY,
 name VARCHAR(50),
 joining_date DATE
);
```

## 3. Views

### What is a View

A View is a virtual table created from a SQL query.

### Example Table

| id | name | salary |
| -- | ---- | ------ |
| 1  | A    | 50000  |

### Create View

```sql
CREATE VIEW high_salary AS
SELECT name, salary
FROM employees
WHERE salary > 40000;
```

### Use View

```sql
SELECT * FROM high_salary;
```
