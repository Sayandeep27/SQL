# MySQL DDL Commands Guide

---

# 1. CREATE DATABASE

## Definition

Creates a new database.

```sql
CREATE DATABASE company_db;
```

---

# 2. DROP DATABASE

Deletes an existing database permanently.

```sql
DROP DATABASE company_db;
```

---

# 3. CREATE TABLE

Creates a new table inside a database.

```sql
CREATE TABLE employees (
    emp_id INT PRIMARY KEY,
    name VARCHAR(50),
    department VARCHAR(50),
    salary INT
);
```

### Example Table

| emp_id | name   | department | salary |
| ------ | ------ | ---------- | ------ |
| 1      | Rahul  | IT         | 60000  |
| 2      | Anjali | HR         | 50000  |
| 3      | Aman   | Finance    | 70000  |

---

# 4. DROP TABLE

Deletes a table permanently.

```sql
DROP TABLE employees;
```

---

# 5. ALTER TABLE

Used to modify an existing table.

## Add Column

```sql
ALTER TABLE employees
ADD email VARCHAR(100);
```

## Drop Column

```sql
ALTER TABLE employees
DROP COLUMN email;
```

## Modify Column

```sql
ALTER TABLE employees
MODIFY salary DECIMAL(10,2);
```

---

# 6. TRUNCATE TABLE

Deletes all rows but keeps the table structure.

```sql
TRUNCATE TABLE employees;
```

---

# Difference Between DELETE, TRUNCATE, and DROP

| Feature       | DELETE | TRUNCATE  | DROP    |
| ------------- | ------ | --------- | ------- |
| Removes rows  | Yes    | Yes       | No      |
| Removes table | No     | No        | Yes     |
| Can use WHERE | Yes    | No        | No      |
| Fast          | Medium | Very Fast | Instant |

# Complete Example Workflow

```sql
CREATE DATABASE company_db;

USE company_db;

CREATE TABLE employees (
emp_id INT,
name VARCHAR(50),
department VARCHAR(50),
salary INT
);

INSERT INTO employees VALUES
(1,'Rahul','IT',60000),
(2,'Anjali','HR',50000),
(3,'Aman','Finance',70000);

ALTER TABLE employees ADD email VARCHAR(100);

TRUNCATE TABLE employees;

DROP TABLE employees;

DROP DATABASE company_db;
```

| Command         | Purpose                              |

| CREATE DATABASE | Creates a database                   |

| CREATE TABLE    | Creates a table                      |
