## 📌 1. SQL Command Types

### DDL (Data Definition Language)

Used to define or modify database structure

**Commands:**

* CREATE → create table/database
* ALTER → modify table
* DROP → delete table/database
* TRUNCATE → delete all data (structure remains)

---

### DML (Data Manipulation Language)

Used to manipulate data inside tables

**Commands:**

* INSERT → add data
* UPDATE → modify data
* DELETE → remove data

---

### DCL (Data Control Language)

Used to control access/permissions

**Commands:**

* GRANT → give permission
* REVOKE → remove permission

---

### TCL (Transaction Control Language)

Used to manage transactions

**Commands:**

* COMMIT → save changes
* ROLLBACK → undo changes
* SAVEPOINT → set checkpoint

---

### DQL (Data Query Language)

Used to fetch data

**Command:**

* SELECT → retrieve data

---

## 📌 2. DELETE vs TRUNCATE

| Feature        | DELETE               | TRUNCATE         |
| -------------- | -------------------- | ---------------- |
| Type           | DML                  | DDL              |
| Purpose        | Remove specific rows | Remove all rows  |
| WHERE clause   | Yes                  | No               |
| Rollback       | Yes                  | Usually No       |
| Speed          | Slower               | Faster           |
| Logging        | Row-level            | Minimal          |
| Auto Increment | Not reset            | Reset            |
| Triggers       | Executes             | Does not execute |

### Example

```sql
DELETE FROM employees WHERE dept_id = 10;
```

```sql
TRUNCATE TABLE employees;
```

## 📌 3. UNION Operator Rules

* Same number of columns
* Same order of columns
* Compatible data types
* Column names from first query
* UNION removes duplicates
* UNION ALL keeps duplicates

### Example

```sql
SELECT name, age FROM students
UNION
SELECT name, age FROM employees;
```

## 📌 4. Convert Text to Date

### Oracle

```sql
SELECT TO_DATE('31-01-2021', 'DD-MM-YYYY') FROM DUAL;
```

### MySQL

```sql
SELECT STR_TO_DATE('31-01-2021', '%d-%m-%Y');
```

### SQL Server

```sql
SELECT CAST('31-01-2021' AS DATE);
```

### PostgreSQL

```sql
SELECT TO_DATE('31-01-2021', 'DD-MM-YYYY');
```

## 📌 5. WHERE vs HAVING

| Feature             | WHERE           | HAVING          |
| ------------------- | --------------- | --------------- |
| Filters             | Rows            | Groups          |
| Works on            | Raw data        | Aggregated data |
| Aggregate functions | No              | Yes             |
| Execution           | Before GROUP BY | After GROUP BY  |

### Example

```sql
SELECT dept_id, salary FROM employees WHERE salary > 50000;
```

```sql
SELECT dept_id, COUNT(*) FROM employees GROUP BY dept_id HAVING COUNT(*) > 5;
```

## 📌 6. View vs Synonym

| Feature     | View          | Synonym |
| ----------- | ------------- | ------- |
| Type        | Virtual table | Alias   |
| Stores data | No            | No      |
| Query       | Yes           | No      |
| Security    | Yes           | No      |

### Example

```sql
CREATE VIEW emp_view AS SELECT name FROM employees;
```

```sql
CREATE SYNONYM emp FOR employees;
```

## 📌 7. Trigger

A trigger is a database object that executes automatically on events.

### Events

* INSERT
* UPDATE
* DELETE

### Example

```sql
CREATE TRIGGER before_insert_emp
BEFORE INSERT ON employees
FOR EACH ROW
BEGIN
    SET NEW.created_at = NOW();
END;
```

## 📌 8. View vs Materialized View

| Feature     | View      | Materialized View |
| ----------- | --------- | ----------------- |
| Stores data | No        | Yes               |
| Performance | Slow      | Fast              |
| Freshness   | Real-time | Needs refresh     |
| Storage     | No        | Yes               |

### Example

```sql
CREATE VIEW high_salary_emp AS SELECT name FROM employees;
```

```sql
CREATE MATERIALIZED VIEW high_salary_emp_mv AS SELECT name FROM employees;
```

```sql
REFRESH MATERIALIZED VIEW high_salary_emp_mv;
```

## 📌 9. Yesterday’s Date

### MySQL

```sql
SELECT CURDATE() - INTERVAL 1 DAY;
```

### PostgreSQL

```sql
SELECT CURRENT_DATE - INTERVAL '1 day';
```

### SQL Server

```sql
SELECT DATEADD(DAY, -1, GETDATE());
```

### Oracle

```sql
SELECT SYSDATE - 1 FROM DUAL;
```
