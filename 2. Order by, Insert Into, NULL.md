# 1. ORDER BY

## What is ORDER BY?

`ORDER BY` is used to **sort the result of a query**.

Sorting can be done in:

* **Ascending order (ASC)** → Smallest to Largest
* **Descending order (DESC)** → Largest to Smallest

---

## Syntax

```sql
SELECT column_name
FROM table_name
ORDER BY column_name [ASC | DESC];
```

---

## Example 1 — Sort by Salary (Ascending)

```sql
SELECT name, salary
FROM employees
ORDER BY salary ASC;
```

Result:

| name  | salary |
| ----- | ------ |
| Ankit | 48000  |
| Amit  | 50000  |
| Neha  | 55000  |
| Rahul | 60000  |
| Rohit | 70000  |

---

## Example 2 — Sort by Salary (Descending)

```sql
SELECT name, salary
FROM employees
ORDER BY salary DESC;
```

Result:

| name  | salary |
| ----- | ------ |
| Rohit | 70000  |
| Rahul | 60000  |
| Neha  | 55000  |
| Amit  | 50000  |
| Ankit | 48000  |

---

## Example 3 — Sort by Multiple Columns

```sql
SELECT name, department, salary
FROM employees
ORDER BY department ASC, salary DESC;
```

Meaning:

* First sort by **department**
* Inside each department, sort by **salary (highest first)**

# 2. INSERT INTO

## What is INSERT INTO?

`INSERT INTO` is used to **add new rows into a table**.

---

## Syntax

```sql
INSERT INTO table_name (column1, column2, column3)
VALUES (value1, value2, value3);
```

---

## Example 1 — Insert One Record

```sql
INSERT INTO employees (id, name, department, salary)
VALUES (6, 'Priya', 'Marketing', 52000);
```

Table after insert:

| id | name  | department | salary |
| -- | ----- | ---------- | ------ |
| 6  | Priya | Marketing  | 52000  |

---

## Example 2 — Insert Multiple Records

```sql
INSERT INTO employees (id, name, department, salary)
VALUES
(7, 'Karan', 'IT', 54000),
(8, 'Sneha', 'HR', 51000);
```

---

## Example 3 — Insert Without Specifying Columns

```sql
INSERT INTO employees
VALUES (9, 'Riya', 'Finance', 56000);
```

Note: Column order must match table structure.

---

## Example 4 — Insert Data From One Table to Another Table

`INSERT INTO ... SELECT` is used to **copy data from one table and insert it into another table**.

### Example Tables

**employees**

| id | name  | department | salary |
| -- | ----- | ---------- | ------ |
| 1  | Amit  | IT         | 50000  |
| 2  | Rahul | HR         | 60000  |
| 3  | Neha  | Finance    | 55000  |

**employees_backup** (destination table)

| id | name | department | salary |
| -- | ---- | ---------- | ------ |

### Syntax

```sql
INSERT INTO destination_table (column1, column2, column3)
SELECT column1, column2, column3
FROM source_table;
```

### Example — Copy All Data

```sql
INSERT INTO employees_backup (id, name, department, salary)
SELECT id, name, department, salary
FROM employees;
```

After execution, **employees_backup** will contain the same rows as **employees**.

### Example — Copy Only Specific Rows

```sql
INSERT INTO employees_backup (id, name, department, salary)
SELECT id, name, department, salary
FROM employees
WHERE department = 'IT';
```

This copies **only IT employees** into the backup table.

# 3. NULL Values

## What is NULL?

`NULL` represents **missing or unknown data**.

It is **not the same as 0 or an empty string**.

Example row:

| id | name  | department | salary |
| -- | ----- | ---------- | ------ |
| 5  | Ankit | NULL       | 48000  |

Here the department value is **missing**.

---

## Insert NULL Values

```sql
INSERT INTO employees (id, name, department, salary)
VALUES (10, 'Arjun', NULL, 47000);
```

---

## Find NULL Values

```sql
SELECT *
FROM employees
WHERE department IS NULL;
```

Result:

| id | name  | department | salary |
| -- | ----- | ---------- | ------ |
| 5  | Ankit | NULL       | 48000  |
| 10 | Arjun | NULL       | 47000  |

---

## Find NOT NULL Values

```sql
SELECT *
FROM employees
WHERE department IS NOT NULL;
```
