# MySQL Aggregate Functions (MIN, MAX, COUNT, AVG, SUM)

---

## 1. What are Aggregate Functions?

Aggregate functions in **MySQL** perform calculations on **multiple rows of data** and return **a single value** as the result.

They are commonly used for:

* Data analysis
* Reporting
* Calculating statistics
* Summarizing data

For example:

* Total sales of a company
* Average salary of employees
* Maximum product price

Aggregate functions process **a column of values** and return **one summarized result**.

---

## 2. Common MySQL Aggregate Functions

| Function    | Description                |
| ----------- | -------------------------- |
| **MIN()**   | Returns the smallest value |
| **MAX()**   | Returns the largest value  |
| **COUNT()** | Returns the number of rows |
| **AVG()**   | Returns the average value  |
| **SUM()**   | Returns the total sum      |

# 1. MIN() Function

## Definition

`MIN()` returns the **smallest value in a column**.

### Syntax

```sql
SELECT MIN(column_name)
FROM table_name;
```

---

## Example 1: Minimum Salary

```sql
SELECT MIN(salary)
FROM employees;
```

### Result

| MIN(salary) |
| ----------- |
| 45000       |

Explanation:

The **lowest salary** in the table is **45000**.

---

## Example 2: Minimum Age

```sql
SELECT MIN(age)
FROM employees;
```

Result:

| MIN(age) |
| -------- |
| 25       |

---

# 2. MAX() Function

## Example 2: Maximum Age

# 3. COUNT() Function

## Definition

`COUNT()` returns the **number of rows**.

### Syntax

```sql
SELECT COUNT(column_name)
FROM table_name;
```

---

## Example 1: Count Employees

```sql
SELECT COUNT(*)
FROM employees;
```

### Result

| COUNT(*) |
| -------- |
| 5        |

Explanation:

There are **5 employees** in the table.

---

## Example 2: Count Salaries

```sql
SELECT COUNT(salary)
FROM employees;
```

Result:

| COUNT(salary) |
| ------------- |
| 5             |

Note:

`COUNT(column)` **ignores NULL values**.

---

# 4. AVG() Function

## Definition

`AVG()` returns the **average value of a numeric column**.

### Syntax

```sql
SELECT AVG(column_name)
FROM table_name;
```

---

## Example: Average Salary

```sql
SELECT AVG(salary)
FROM employees;
```

### Result

| AVG(salary) |
| ----------- |
| 58000       |

Explanation:

Average = (60000 + 45000 + 70000 + 50000 + 65000) / 5

= **58000**

---

# 5. SUM() Function

## Definition

`SUM()` returns the **total of a numeric column**.

### Syntax

```sql
SELECT SUM(column_name)
FROM table_name;
```

---

## Example: Total Salary

```sql
SELECT SUM(salary)
FROM employees;
```

### Result

| SUM(salary) |
| ----------- |
| 290000      |

Explanation:

Total Salary =

60000 + 45000 + 70000 + 50000 + 65000 = **290000**

---

# Using Aggregate Functions with WHERE

Aggregate functions can be combined with **WHERE** to filter rows.

### Example: Average Salary in IT Department

```sql
SELECT AVG(salary)
FROM employees
WHERE department = 'IT';
```

Result:

| AVG(salary) |
| ----------- |
| 65000       |

Explanation:

IT salaries:

60000, 70000, 65000

Average = **65000**

---

# Using Multiple Aggregate Functions Together

You can use multiple aggregate functions in one query.

```sql
SELECT
MIN(salary),
MAX(salary),
AVG(salary),
SUM(salary),
COUNT(*)
FROM employees;
```

### Result

| MIN   | MAX   | AVG   | SUM    | COUNT |
| ----- | ----- | ----- | ------ | ----- |
| 45000 | 70000 | 58000 | 290000 | 5     |
